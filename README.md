One line, 200 characters at most: an absurd clause hidden deep inside a
terms-of-service agreement. Deadpan legal boilerplate that quietly turns
absurd.

## Entry

> By accepting these terms, you agree to surrender one (1) left sock per
> calendar month, to be collected by a Company representative at a time of
> our choosing.

157 characters, one sentence, plain text.

## How it works

`main.py` is a stdlib-only copier: it copies the pre-written `entry.txt`
into the output directory (`MAKEFUN_OUTPUT_DIR`, default `output/`).
Nothing is rendered or generated at run time, so the output is
byte-identical on every run.
